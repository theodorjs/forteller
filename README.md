# Fortellerverksted

Et digitalt verksted for å finne byggeklossene til en historie. Velg mellom tre verktøy:

- **Lykkehjul** – snurr hjulene for person, sjanger, sted, ting og tid.
- **Spillkort** – trekk kort fra fargede kortstokker og samle dem i hånden.
- **Eventyrkart** – følg Heltens reise steg for steg på et kart i en åpen bok.

Egne sett med kriterier kan lages, lagres og byttes mellom i verktøymenyen. Resultatet kan deles som tekst eller som bilde.

**Prøv den:** <https://theodorjs.github.io/forteller/>

## Kjøre lokalt

Hele appen er én selvstendig fil. Åpne `index.html` i en nettleser – ingen installasjon eller byggesteg trengs.

## Publisering

Siden publiseres med GitHub Pages fra `main`-grenen (rotmappen).
